# Next.js : lire la documentation livrée avec le paquet

Cette version de Next.js (16) diffère de ce que ta mémoire d'entraînement connaît (params asynchrones,
`proxy.ts` au lieu de `middleware.ts`, Turbopack par défaut…). Avant d'écrire du code Next.js, lis le guide
correspondant dans `node_modules/next/dist/docs/`.
